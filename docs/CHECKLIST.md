# 真机检查清单（iPhone 与安卓各跑一遍）

网址：https://bencongtang673-beep.github.io/openai-quota-watch/ （合并 PR、Pages 部署完成后可用）

## 两端都要做
| # | 检查项 | 怎么做 | 预期 |
|---|---|---|---|
| 1 | 安装到主屏幕 | iPhone：Safari → 分享 → 添加到主屏幕；安卓：Chrome 首页「安装」或 ⋮ → 安装应用 | 桌面出现“数独”图标，打开后没有浏览器地址栏 |
| 2 | 飞行模式下游玩 | 先联网打开一次 → 开飞行模式 → 从图标冷启动 → 新游戏（经典/杀手/武士各开一局）→ 看历史 | 都能正常打开、出题、游玩 |
| 3 | 杀进程后恢复（含撤销历史） | 在一局里填 5 个数、记 2 个笔记 → 上滑杀掉 App → 重新打开 → 继续上一局 → 连按撤销 | 盘面、笔记、用时原样；撤销能一步步退回 |
| 4 | 多残局并存 | 开 3 局不同模式，各填几格 → 首页「未完成的局」 | 3 局都在，进度/用时/最后游玩时间正确，互不影响 |
| 5 | 更新后存档仍在 | 等我推送新版本并合并后：打开 App（第一次打开会在后台下载）→ 完全关闭 → 再打开 | 底部提示“已更新到新版本”，残局与历史都在；对局中途不会被强制刷新 |
| 6 | 备份跨平台恢复 | iPhone：备份 → 导出为文本码（或 JSON 文件）→ 发到安卓 → 安卓：备份 → 粘贴导入（反向再做一次） | 残局（含撤销历史）、历史记录、统计、设置都出现在另一台手机上 |
| 7 | 音效 | 设置里打开音效，填数、记笔记、擦除、撤销、填错、完成一行、通关 | 各有不同的柔和音色；快速连点不爆音；正在听的音乐不被打断 |

## 仅 iPhone
| # | 检查项 | 预期 |
|---|---|---|
| 8 | 静音键打开时玩一局 | 网页音效不响（系统行为，设置页已注明）；关掉静音键后恢复 |
| 9 | Safari 标签页（非主屏幕）打开 | 首页顶部出现“Safari 会清除长期未访问网站的数据…”提示，可点“知道了”关闭且不再出现 |
| 10 | 双指在页面上捏合 | 页面不会被缩放 |

## 仅安卓
| # | 检查项 | 预期 |
|---|---|---|
| 11 | 返回键 | 打开“更多”菜单按返回 → 菜单关闭；对局中按返回 → 回首页；首页按返回 → 退出 |
| 12 | 震动 | 设置里有“震动”开关；填数时有 10–20ms 短震；关闭后不震 |
| 13 | 强制深色 | 系统开启深色（及开发者选项“覆盖强制深色”）| 配色是 App 自己的深色主题，数字、格线清楚，没有反色错乱 |
| 14 | 系统字体放大 | 设置 → 显示 → 字体大小调到最大 / Chrome 文字缩放 200% | 布局不崩，按键仍可点，盘面数字大小只随格子变化 |
